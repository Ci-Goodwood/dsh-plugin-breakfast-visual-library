| effects.js | 8种通用图片运动机制重新用Canvas实现 | 不捆绑PowerPoint底稿、NASA照片或生成主体；不依赖Office/Morph |

代码移植来自制作者的本地工作成果，但这些本地目录不是运行依赖。运行只用当前目录中的文件。

## 明确排除、不能默认放行的来源

- HOI4纹理/游戏文件：不进本模块。旧研究截图仍在本地隔离区，首版几何的研究来源关系见上表；没有因“重绘”就替原游戏文件宣称商用许可。
- 5175套公开用户配色：公开可看不等于授权清楚，本轮不复制数据、不提供自动下载入口。旧数据只能按本地研究资料管理，入成片/分发前逐项核对作者与条款。
- 中国色色表、历史疆域与交通地图、CHGIS数据、参考视频、照片、字体、PPT底稿：均不进入本次提交。
